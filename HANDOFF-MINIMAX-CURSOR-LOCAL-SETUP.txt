WHAT MUST BE CONFIGURED LOCALLY (ACTION_REQUIRED)

The Cursor model picker lives in your LOCAL Cursor app, not in the cloud.
Cloud configuration here does NOT make models appear in your Cursor UI.

You must perform setup on your local PC/Mac/Linux.

--------------------------------------------------------------------------------
FASTEST PATH — MANUAL UI IN CURSOR (RECOMMENDED)
--------------------------------------------------------------------------------

1. Open Cursor on your local machine
2. Go to:
     Cursor → Settings → Models
   (or press Cmd/Ctrl+Shift+P → "Cursor Settings: Open Models")
3. Enable: [OpenAI API Key] toggle
4. Paste your MiniMax API key in the OpenAI API Key field
5. Enable: [Override OpenAI Base URL] toggle
6. Enter base URL:
     https://api.minimax.io/v1
7. In "Custom Models" section, add:
     MiniMax-M3
8. Enable the toggle for MiniMax-M3
9. Optionally add and enable fallback models:
     MiniMax-M2.7-highspeed
     MiniMax-M2.7
     MiniMax-M2.5-highspeed
     MiniMax-M2.5
     MiniMax-M2.1
     MiniMax-M2
10. Select MiniMax-M3 in the model picker dropdown
11. Send a test message to confirm it works

--------------------------------------------------------------------------------
DB PATCH SCRIPT (ADVANCED / OPTIONAL)
--------------------------------------------------------------------------------

File: scripts/patch-cursor-minimax-vscdb.py

Usage (Cursor must be FULLY CLOSED):

  # Linux
  python3 scripts/patch-cursor-minimax-vscdb.py \
    --db ~/.config/Cursor/User/globalStorage/state.vscdb \
    --env-file ~/.cursor-minimax/local.env

  # macOS
  python3 scripts/patch-cursor-minimax-vscdb.py \
    --db "~/Library/Application Support/Cursor/User/globalStorage/state.vscdb" \
    --env-file ~/.cursor-minimax/local.env

  # Dry run first (no changes)
  python3 scripts/patch-cursor-minimax-vscdb.py --db <path> --dry-run

DIRECT API TEST (outside Cursor)
--------------------------------------------------------------------------------

Run on any machine with internet access and your API key:

  export MINIMAX_API_KEY="your-key-here"

  curl -s \
    -H "Authorization: Bearer $MINIMAX_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"MiniMax-M3","messages":[{"role":"system","content":"Reply with exactly OK."},{"role":"user","content":"ping"}],"max_tokens":16}' \
    https://api.minimax.io/v1/chat/completions \
  | python3 -c "import sys,json; d=json.load(sys.stdin); print('SUCCESS:', d['choices'][0]['message']['content'] if 'choices' in d else d.get('error','FAIL'))"

Expected output if working: SUCCESS: OK

--------------------------------------------------------------------------------
KNOWN BLOCKERS
--------------------------------------------------------------------------------

1. Cursor Pro / paid plan may be required for custom OpenAI-compatible models.
   Free tier may not support custom base URL override.

2. OPENAI_API_KEY and OPENAI_BASE_URL system environment variables can
   override Cursor settings — unset them if they conflict.

3. State.vscdb must only be patched when Cursor is fully closed.
   Patching while Cursor is running causes corruption.

4. Some Cursor versions may require "Developer: Reload Window" after adding models.
