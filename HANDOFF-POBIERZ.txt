  Baza: state.vscdb (SQLite) na Twoim urządzeniu.

Status: DO ZROBIENIA NA TWOIM PC (nie da się zdalnie z serwera agenta)

Wymagania:
  - Cursor Pro (custom modele MiniMax — wymóg MiniMax/Cursor)
  - Cursor 2.4+ zalecany
  - Base URL: https://api.minimax.io/v1

Instalacja (zamknij Cursor całkowicie!):

  cd /ścieżka/do/repo/akm-bridge
  bash minimax-dual-setup/local-cursor/install.sh

Co robi skrypt:
  - Tworzy ~/.cursor-minimax/local.env (osobny plik, tylko na Twoim PC)
  - Patchuje state.vscdb (API key + base URL + modele)
  - Aktualizuje settings.json
  - Backup: state.vscdb.bak-minimax

Po instalacji:
  1. Uruchom Cursor
  2. Settings → Models → OpenAI API Key = ON (toggle)
  3. Override OpenAI Base URL = https://api.minimax.io/v1
  4. View All Models → Add Custom Model → MiniMax-M3
  5. Włącz toggle przy MiniMax-M3
  6. Wybierz w pickerze

Jeśli picker pusty:
  - Sprawdź Cursor Pro
  - Settings → Network → HTTP Compatibility Mode → HTTP/1.1
  - Usuń OPENAI_API_KEY / OPENAI_BASE_URL ze zmiennych systemowych (kolidują)
  - Developer: Reload Window

Weryfikacja:
  python3 scripts/patch-cursor-minimax-vscdb.py verify
  python3 scripts/patch-cursor-minimax-vscdb.py inspect

Ścieżki state.vscdb:
  Linux:   ~/.config/Cursor/User/globalStorage/state.vscdb
  macOS:   ~/Library/Application Support/Cursor/User/globalStorage/state.vscdb
  Windows: %APPDATA%\Cursor\User\globalStorage\state.vscdb
